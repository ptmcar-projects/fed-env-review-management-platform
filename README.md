# Federal Environmental Review Management Platform

A portfolio case study and software prototype for improving project tracking, milestone management, document coordination, and executive visibility during federal environmental reviews and permitting.

## Project focus

This project does **not** attempt to change NEPA requirements or automate environmental decisions.

It focuses on the operational technology used to coordinate complex federal reviews:

- projects;
- participating agencies;
- environmental reviews and authorizations;
- milestones and target dates;
- schedule changes and pauses;
- documents;
- issues and dependencies;
- status reporting; and
- management visibility.

## Why this project is real

The federal government already operates the public Federal Permitting Dashboard, which tracks infrastructure projects and their environmental-review and authorization milestones. The government also publishes downloadable project and milestone data.

This repository uses those public processes and data structures as the evidence base for a fictional modernization engagement.
